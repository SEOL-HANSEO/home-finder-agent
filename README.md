# 무료주차장 찾기

공공데이터포털의 무료 주차장 정보를 조회하는 Flask 앱입니다. 첫 화면에서는 검색 결과를 표시하지 않습니다. 지역을 검색하면 위치의 직선거리 3km 이내에서 비로그인 사용자에게 최대 5곳, 로그인 사용자에게 전체 결과를 보여줍니다.

## Supabase 설정

Supabase 프로젝트의 SQL Editor에서 `supabase/schema.sql`을 실행합니다. 프로젝트 URL, publishable key, 서버 전용 secret key와 공공데이터 인증키를 `.env`에 설정합니다. `.env.example`에 항목 이름이 있습니다. `.env`는 Git에 포함되지 않습니다. secret key는 서버에서 활동 기록을 쓰는 데만 사용합니다.

Supabase Auth에서 이메일과 비밀번호 인증을 사용합니다. 이메일 확인 설정이 켜져 있으면 가입 후 확인이 필요합니다. 로그인 사용자에게 관리자 권한을 부여하려면 SQL Editor에서 아래 문장의 이메일을 실제 계정으로 바꾸어 실행합니다.

```sql
insert into public.parking_admins (user_id)
select id from auth.users where email = '관리자 이메일'
on conflict do nothing;
```

`supabase/admin_ownership.sql`을 추가로 실행하면 기존 관리자 한 명이 최고 관리자가 됩니다. 최초 실행 시 관리자가 정확히 한 명이어야 하며, 이후 최고 관리자만 관리자 화면에서 상대방의 가입 이메일로 관리자 권한을 부여하거나 해제할 수 있습니다. 일반 관리자는 관리자 권한을 부여하거나 해제할 수 없지만 활동 기록을 볼 수 있습니다. 최고 관리자는 자신의 관리자 권한을 해제할 수 없습니다.

관리자만 앱의 활동 기록 화면에 접근할 수 있습니다. 활동 기록은 시각, 계정 별칭, 행동, 판정, 결과 수, 주차정보 제공자 호출 횟수만 저장합니다. 비밀번호, 토큰, 검색어를 저장하지 않습니다. 로그 저장이 실패하면 서버에 오류가 표시됩니다.

세션 토큰은 서버의 `instance/sessions.sqlite3`에 저장되며 브라우저에는 임의 세션 식별자만 전달합니다. 앱은 로컬 실행용이며 서버 재시작이나 인증 토큰 만료 후 다시 로그인해야 할 수 있습니다. HTTPS 배포 시 `SESSION_COOKIE_SECURE=true`를 설정합니다.

## 실행

```bash
/home/kim/work/my-agent/.venv/bin/python app.py
```

브라우저에서 http://127.0.0.1:5000 을 엽니다. 가상환경이 없으면 `python3 -m venv ../.venv`와 `../.venv/bin/python -m pip install -r requirements.txt`를 실행합니다.

위치는 OpenStreetMap Nominatim으로 검색하고, 서비스 장애 시 Photon을 대체 사용합니다. 카카오 지도 JavaScript SDK 키를 `KAKAO_MAP_JAVASCRIPT_KEY` 환경 변수에 설정하면 검색 결과 지도와 챗봇 지도 조작에 카카오맵을 사용합니다. 키가 없으면 OpenStreetMap 지도를 표시합니다. 카카오 개발자 콘솔의 JavaScript SDK 도메인에 서비스 주소를 등록해야 합니다. 주차장 데이터는 실시간 빈자리 정보가 아니며 데이터 기준일과 실제 현장 상황이 다를 수 있습니다.

## 주차장 즐겨찾기

`supabase/favorites.sql`을 적용한 뒤 로그인하여 주차장을 검색하면 결과의 별 버튼으로 저장할 수 있습니다. 내 즐겨찾기 목록에서 확인하거나 삭제할 수 있으며 다른 계정의 목록은 볼 수 없습니다. 같은 주차장을 다시 저장해도 중복되지 않습니다.

새로운 장소를 찜하면 `새로 찜했어요` 결과와 `즐겨찾기 목록 열기` 행동을 표시하고 목록으로 이동합니다. 이미 찜한 장소라면 `이미 찜한 주차장이에요` 결과와 `기존 항목 찾아 표시` 행동을 보여주고 해당 항목을 강조합니다. 버튼, 한 줄 요청, 챗봇이 같은 저장 결과를 사용합니다. 결과에 따른 행동은 정해진 규칙으로 선택하며, AI 모델이 설정되지 않은 경우에는 `모의 선택`이라고 표시합니다.

검색 결과 아래 한 줄 요청에 `1번 즐겨찾기 추가`라고 입력하면 같은 목록에 저장됩니다. AI가 연결되고 횟수가 남은 경우 AI가 요청을 해석하며 챗봇과 이용 한도를 공유합니다. 이때 요청과 검색 결과의 이름·주소가 Google에 전송됩니다. AI를 사용할 수 없으면 `모의 선택`으로 표시하고 위 예문 형식으로 실행합니다. 한 줄 요청은 현재 검색 결과 앞 최대 30곳 중에서 선택합니다.

## 문장으로 주차장 추천

추가 데이터베이스 설정으로 Supabase SQL Editor에서 `supabase/ai_quota.sql`을 실행합니다. 챗봇은 검색·로그인·회원가입·관리자 화면에서 열 수 있으며, 현재 브라우저 탭에서 화면을 이동해도 대화가 유지됩니다.

챗봇에서 지역 검색을 요청하면 검색창, 결과 목록, 지도에 같은 결과가 반영됩니다. 이어서 `첫 번째 즐겨찾기해줘`, `2번 지도에서 보여줘`, `현재 검색을 기본으로 저장해줘`, `다크 모드로 바꿔줘`처럼 요청할 수 있습니다. 로그인한 계정에서 즐겨찾기를 추가·삭제하거나 기본 설정을 저장할 수 있습니다. 화면 이동, 로그아웃, 최고 관리자의 관리자 권한 변경에도 기존 권한 검사가 적용되며 비밀번호는 챗봇이 아닌 로그인 화면에서 입력합니다.

비로그인 사용자는 접속 네트워크 기준 하루 3회, 로그인 회원은 계정당 하루 5회 이용할 수 있습니다. 관리자는 개인별 제한 없이 전체 AI 한도 내에서 이용할 수 있습니다. 한국 시간 자정에 개인별 횟수를 초기화합니다. 같은 네트워크를 쓰는 비로그인 사용자는 횟수를 공유할 수 있습니다. Gemini 프로젝트를 보호하기 위해 전체 AI 요청은 Google의 태평양 시간 기준 하루 30회로 제한하고, 그중 일반 사용자 요청은 20회까지만 허용합니다. Google의 실제 한도는 프로젝트별로 다를 수 있습니다. AI 응답이나 주차장 조회에 실패해도 차감되며, 빈 메시지와 AI 미설정 상태는 차감하지 않습니다.

AI 대화에는 Gemini `gemini-3.1-flash-lite`를 사용합니다. 반드시 **결제가 연결되지 않은 무료 프로젝트**의 API 키를 발급받아 서버의 `GEMINI_API_KEY`에 설정한 뒤 `GEMINI_FREE_TIER_CONFIRMED=true`를 설정하세요. 이 변수는 관리자의 확인 표시이며, 앱이 Google의 실제 결제 상태를 검증하거나 비용을 차단하는 기능은 아닙니다. 결제가 연결된 프로젝트에는 사용하지 마세요. Google의 무료 이용 한도가 소진되면 오류를 표시하며 다른 모델이나 유료 서비스로 전환하지 않습니다.

대화 내용은 답변을 위해 Google에 전달되며 무료 서비스에서는 Google 제품 개선에 사용될 수 있습니다. 민감한 개인정보는 입력하지 마세요. 최근 대화는 서버 세션과 현재 브라우저 탭에 보관되어 화면 이동 및 로그인·로그아웃 후에도 유지됩니다. 주차장 검색 결과는 AI가 생성하지 않고 공공데이터에서 반경 3km 안의 주차장을 찾아 직선거리순으로 최대 3곳 표시합니다.

## Render 배포 준비

`render.yaml`은 Python 웹 서비스와 운영용 Gunicorn 실행 명령을 정의합니다. 배포 환경에서 `PARKING_API_KEY`, `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SECRET_KEY`를 Render 환경 변수로 설정합니다. 실제 키는 저장소나 `render.yaml`에 넣지 않습니다. Supabase Auth의 사이트 URL과 이메일 확인 리디렉션 허용 URL도 배포 주소에 맞춰 설정해야 합니다.

세션과 검색·인증 요청 제한은 서버의 로컬 SQLite에 저장됩니다. Render의 임시 파일 시스템에서는 재시작이나 재배포 후 세션과 제한 기록이 사라질 수 있으며, 서버를 여러 인스턴스로 확장하면 공유되지 않습니다. 이 구성은 단일 인스턴스용이며 전체 요청 제한으로 인해 한 사용자의 과도한 요청이 다른 사용자를 제한할 수 있습니다. 다중 인스턴스 운영에는 공유 저장소와 추가적인 남용 방어가 필요합니다. 배포 후 실제 외부 연결과 인증 과정을 확인하세요.
