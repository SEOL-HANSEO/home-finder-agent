# 🏠 홈파인더 자율 에이전트 (HomeFinder Agent)

> 나니아랩 PBL 01회차: 내 에이전트 정하기와 첫 화면 & 에이전트 자동화 시스템

사용자가 매일 직방, 다방, 네이버 부동산을 일일이 검색하지 않아도, **설정한 조건(직장, 예산, 통근 스타일)을 바탕으로 에이전트 파이프라인이 24시간 자율 탐색 및 스크리닝을 수행**하는 차세대 부동산 자동화 서비스입니다.

---

## 🎯 왜 '에이전트 자동화'인가?
1. **기존 방식:** 사람이 직접 수십 개 지하철 노선과 지도를 뒤지며 월세와 관리비를 일일이 엑셀에 계산하고 비교해야 함.
2. **홈파인더 에이전트 방식:**
   * **탐색 에이전트(Scout):** 직장 기준 30분 반경 통근 클러스터 자동 계산
   * **수집 에이전트(Crawler):** 부동산 플랫폼의 신규 급매물 실시간 감시
   * **위험분석 에이전트(Risk):** 등기부 대출금(근저당) 및 깡통전세 자동 스크리닝
   * **비용 에이전트(Cost):** 숨은 관리비와 교통비까지 합산한 한 달 실부담액 자동 도출

---

## 🚀 주요 기능
* **자율 탐색 파이프라인 시뮬레이션 콘솔:** 상단 `[⚡ 자동 탐색 파이프라인 가동]` 버튼 클릭 시 에이전트 간 협업 및 데이터 스크리닝 로그가 실시간 터미널 스타일로 시각화됩니다.
* **100% 무인증 고화질 지도 & 매물 바로가기:** 오픈스트리트맵 기반의 안전한 인터랙티브 지도와 네이버/직방 1초 검색 연동.
* **숨은 주거비 계산기:** 월세 + 관리비 + 교통비를 합산한 실제 한 달 지출액 자동 계산.
